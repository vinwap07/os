		Лабораторная работа №1

Установка Linux и способы входа.

1. Ознакомиться с классификацией гипервизоров.

2. Ознакомится с типами подключения виртуальных машин к сети (01-VB-networks.pdf). 
Рекомендуемый гипервзор – Oracle VirtualBox.
Допустимо использовать любой по желанию.

3. Выбрать любой тип подключения виртуалки к сети, позволяющий из
хостовой системы получить доступ к гостевой через сеть.

4. Выполнить установку в виртуальную машину ОС Linux. Для справки
прилагается руководство по установке RHEL. Выбор дистрибутива – по
желанию, любой универсальный дистрибутив (Ubuntu/RHEL/Debian/etc).
Специализированные, нишевые дистрибутивы могут не иметь достаточной
функциональности для выполнения всех будущих лабораторных работ.
Жалобы типа “у нас этого в нашем Linux-е нет” - не принимаются.

- В установленной ОС задать имя хоста – латиницей, первая буква имени и
фамилия студента.
- Создать пользователя. Имя пользователя - латиницей, первая буква имени и
фамилия студента (совпадает с именем хоста).

5. Прочитать первую главу курса Redhat-VB-а. Уметь выполнять подключение к
своей виртуальной машине в локальной консоли и через ssh – с паролем или с
использованием ключа. SSH клиент – любой по своему выбору.

Форма сдачи работы:
1. Уметь:
- демонстрация локального входа
- демонстрация удаленного входа (с хоста) через ssh на гостя.
- демонстрация удаленного входа (с хоста) через ssh на гостя c аутентификацией
по ключу.
2. Сдача сопровождается ответами на вопросы по теме работы (например, где и как
настроен удаленный доступ, где храняться конфиги, ключи, etc).

Оценка работы:
1. Базовый срок выполнения работы – 1 неделя. Вовремя сданная полностью
выполненная работа – 3 балла.
2. Полностью сданная работа – демонстрация и ответы на вопросы.
3. Только демонстрация (успешная), без ответов на вопросы: 2 балла.
4. Работа сданная через 2 недели – половина баллов, позже работа не
принимается.
